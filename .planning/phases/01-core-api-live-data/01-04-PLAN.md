## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| apps/api → upstream APIs | Untrusted JSON crosses from the public internet into the process — must be zod-gated before touching state |
| process env → OpenAQ client | The API key exists only as an environment variable and must never reach a URL, log line or response |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-08 | Tampering | all four clients | mitigate | zod `safeParse` per upstream → typed `{ok:false}` failure; malformed/hostile payloads degrade that one section (ASM-04 foundation); no eval, no HTML passthrough — responses are JSON numbers/strings only |
| T-01-09 | Information Disclosure | clients/openaq.ts key | mitigate | Key read only from `process.env.OPENAQ_API_KEY`, sent in the `X-API-Key` header (never a query string); missing key refuses before any fetch (D-10); no mock mode exists to leak |
