<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| developer machine → AWS CloudFormation / SAM | Deployment privileges and IAM role creation for Lambda Function |
| Lambda Function URL → Public Internet | Unauthenticated HTTP ingress invoking the Lambda function |
| Environment variables → CloudFormation template | Sensitive API keys (`OPENAQ_API_KEY`) passed into Lambda runtime |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Information Disclosure | SAM CloudFormation template | mitigate | Mark `OpenAqApiKey` with `NoEcho: true` in `template.yaml`; never echo or output the parameter in CloudFormation Outputs or build logs (D-07). |
| T-03-02 | Denial of Service | Lambda Function URL | mitigate | Configure `ReservedConcurrentExecutions: 10` and `Timeout: 10` to avoid runaway Lambda billing and rate-limiting from upstreams (PRD §12). |
| T-03-03 | Security Misconfiguration | Function URL CORS | mitigate | In Pass 1, `AllowedOrigin` is temporary wildcard `*` to bootstrap Amplify; in Plan 03-02 Pass 2, origin is locked down strictly to the deployed Amplify origin. CORS is configured exclusively on FunctionUrlConfig so no duplicate ACAO headers are emitted. |
</threat_model>
