<task id="05-01-02" type="execute">
<title>Implement Saved Places Hook, Chip Bar, and Search Bookmark Toggle (SHR-03)</title>
<description>
1. Create `apps/web/src/hooks/useSavedPlaces.ts`:
   - Synchronous hydration from `localStorage.getItem("breeze:saved-places")` with error handling.
   - Schema: `Array<{ lat: number, lon: number, name: string }>`.
   - Functions: `places`, `isCurrentSaved`, `toggleSaveCurrent()`, `removePlace(place)`.
   - Returns `{ action: 'saved' | 'removed' | 'limit_reached' }` when toggling. Max 5 places enforced.
2. Create `apps/web/src/components/SavedPlacesBar.tsx`:
   - Horizontal scrolling strip of pills (`overflow-x-auto no-scrollbar flex items-center gap-2 py-1`).
   - Clicking a chip selects that place via `onSelectPlace`.
   - Chip active state: highlight with `border-blue-600 bg-blue-50 text-blue-900` if coordinates match current location within 0.02° (~2.2 km).
   - Discrete (X) icon on each chip with `aria-label={`Remove ${place.name} from saved places`}` that calls `removePlace`.
3. Update `apps/web/src/components/SearchBox.tsx`:
   - Add a bookmark toggle icon button in the search bar to save/unsave current location.
   - Calls `toggleSaveCurrent()` and triggers appropriate toast ("Saved [Place]", "Removed [Place]", or "Maximum 5 places saved. Remove one to save another.").
4. Mount `SavedPlacesBar` in `App.tsx` between the Search bar and the content cards.
</description>
<verification>
