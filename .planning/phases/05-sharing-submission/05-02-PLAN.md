<task id="05-02-02" type="execute">
<title>Implement shareCardCapture utility with double-pass loop and Web Share fallback</title>
<description>
1. Create `apps/web/src/lib/shareCardCapture.ts`:
   - Function `captureAndShareCard({ element, placeName, verdict, pm25, canonicalUrl, onToast })`.
   - **Step 1: Font readiness guard:** Await `document.fonts.ready` if available.
   - **Step 2: WebKit warm-up pass:** Run `toPng(element, { cacheBust: true })` and discard result to warm SVG foreignObject rasterizer.
   - **Step 3: Settling frame delay:** 150 ms RAF timeout delay.
   - **Step 4: True capture pass:** Run `toBlob(element, { width: 1080, height: 1350, canvasWidth: 1080, canvasHeight: 1350, pixelRatio: 1 })`.
   - **Step 5: File packaging:** Construct `new File([blob], `breeze-${slug}.png`, { type: 'image/png' })`.
   - **Step 6: Native Web Share:** Check `navigator.canShare?.({ files: [file] })`:
     - If true: call `navigator.share({ files: [file], title: `Air in ${placeName}`, text: `Air in ${placeName} is "${verdict}". Check live: ${canonicalUrl}` })`.
     - Handle `AbortError`: exit silently (user canceled share sheet).
     - Handle other errors or unsupported platform: trigger fallback download + copy link.
   - **Step 7: Fallback download & link copy:**
     - Create anchor element with `URL.createObjectURL(blob)` and `download` attribute, trigger click.
     - Call `navigator.clipboard.writeText(canonicalUrl)`.
     - Show toast: *"Card downloaded & link copied to clipboard!"*.
</description>

Unit test capture lifecycle mocking `toBlob`, `navigator.canShare`, `navigator.share`, and download fallback.
